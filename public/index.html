    Run it live

    Runs one case through the real pipeline now: the model reads the note, a second call checks each span in its sentence, the graph decides, and for an appealable case the model drafts the letter and the checker scores its citations. Edit the note to see the verdict change. It needs the access code, and a run can take a minute or more.

    Stand-in mode: no model is called on this deployment. Each step's answer is canned from the case's answer key, so the pipeline, the graph and the citation check run for real, but an edited note won't change what's read. Take out a quoted line and the stand-in's evidence fails its check, as a model's would.

      Live mode, which runs the model on a case you pick, is off on this deployment. Source code and method: github.com/jagnyesh/rcm-ai.
